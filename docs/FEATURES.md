# The Outlast Trials Session Toolkit — feature reference

The Outlast Trials Session Toolkit brings group planning and equipment notes into one section-based interface. Session records provides the third part of the workflow.

| Section | Description |
|---|---|
| Group planning | A dedicated section for group planning and the configuration details associated with that area. |
| Equipment notes | Equipment categories and the associated selection or configuration options. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
